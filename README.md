One joke about Monday mornings, written by `main.py` to `/output/entry.txt` for the [Monday Morning Punchlines](https://make.fun/c/u-gentle-badger-68-monday-morning-punchlines-709645dc?ref=h379tqrk) competition on make.fun.

The joke: Monday auto-renewed the weekend's free trial — and there's no cancel button, just a 9 a.m. meeting with HR.

Run it with `python3 main.py` (respects `$MAKEFUN_OUTPUT_DIR`, defaults to `/output`).
